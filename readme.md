## 一、软件简介

### 1.1 一句话介绍

**GEO霸屏系统，是一套帮企业「被搜到、被 AI 提到」的推广执行系统。**

产品做完了，客户搜不到；AI 回答里，也从来不出现你的名字——这是今天很多企业最贵、却最容易被忽略的损失。

GEO霸屏系统把复杂的推广拆成一件件**确定性动作**：诊断站点、生成符合搜索引擎与 AI 偏好的内容、分发到合适的平台、再回测效果。能自动化的，系统替你做；需要人判断和署名的，系统把文案、步骤、话术全部备好，你点最后一下。

我们不承诺排名，只交付过程——**让每一次推广都可查、可复盘。**

---

### 1.2 它解决什么问题

今天企业推广面临的是一个「双入口」时代：

- **老入口还在**——百度、360、搜狗，客户还在搜；
- **新入口已来**——豆包、DeepSeek、通义千问、腾讯元宝、文心一言、Kimi，客户已经开始直接"问 AI"。

结果是：**很多企业同时在新旧两个入口上"失语"**。客户搜企业名搜不到，问 AI"这个行业哪家靠谱"，AI 报出来的名单里也没有你。

更麻烦的是，企业面对这件事时往往两手空空：

- 知道要做，但**不知道从哪下手**；
- 花钱买了服务，但**说不清效果在哪**；
- 面对新出来的 AI 搜索，**完全摸不着门**。

GEO霸屏系统就是冲着这三个"不知道"来的——把这件事从"玄学"变成"动作"。

### 1.4 核心优势与特色

**① 确定性动作，不玩玄学。**
行业里充斥着"包上首页""保证被 AI 推荐"的承诺，我们不做，也做不了。GEO霸屏系统交付的是**可执行、可验证、可复盘的动作清单**：诊断 → 生成 → 分发 → 回测，每一步都看得见、查得到。推广效果受行业、竞争、时间多重影响，但"动作有没有做到位"，是系统能替你盯住的。

**② 人机协同——不是全自动，也不是纯手工。**
能自动化的（站点体检、内容生成、AI 可见度检测、效果回测）系统全包；需要判断、需要署名、需要真人出面的（对外投稿、平台对接、内容发布），系统把文案、步骤、邮箱、话术都备好，你点最后一下。**机器做机器擅长的，人做人擅长的**，这才是当下真正跑得通的路径。

**③ 注册即送企业官网，个人版永久免费。**
10 套模板任选、7 个栏目齐全（首页 / 产品服务 / 解决方案 / 客户案例 / 关于我们 / 新闻动态 / 联系方式）。而且**不是空壳**——每套模板自带填充内容，改一改就是你的。对很多小微企业和个体户来说，这就是"从 0 到 1"的第一块砖，而且不要钱。

**④ GEO 与 SEO 打通，两个入口一起抓。**
不只做搜索引擎，也做 AI。AI 爬虫白名单、服务端直出、结构化数据（JSON-LD）、答案前置短句、实体一致性……这些"用户看不见的活"，恰恰决定了 AI 会不会引用你。**GEO 不是 SEO 的替代品，是它的下一层。**

**⑤ 城市分站矩阵，区域长尾一网打尽。**
一个城市一个站，区域长尾词自动铺设（如"成都 GEO""成都 AI 搜索优化"）。路径式伪静态 `yaduoo.cn/geo/{城市}`，不需要复杂域名配置。**300 个城市 = 9000+ 区域关键词**，这是纯手工优化不可能完成的规模。

**⑥ 资源中心 14 大类，按"AI 可信度"排序。**
从企业信息核验平台（天眼查/企查查/爱企查）、百科、问答社区，到权威媒体、行业垂直、B2B、地图本地……按"AI 判断你可信度"的逻辑排优先级，而不是随便堆一份外链清单。**AI 认不认你，看的是多源一致 + 权威背书，光铺外链没用。**

**⑦ 结果回填换积分，把机器与人的活拧成一个闭环。**
有些事机器一步都帮不上（比如给行业媒体投稿），我们就把它列成清单交给你做——做完回来填个结果，同样拿积分。**积分奖励"你真的做了事"，不奖励发帖量**，这是这套体系不跑偏的关键。

**⑧ 桌面客户端，升级免发版。**
Windows 客户端只是个"壳"，业务全在云端。我们改了系统、加了功能，你那边**重新打开就是最新的，不用重装、不用更新**。它还会常驻托盘，每天提醒你处理"今天的 3 件事"。

**⑨ 合规底线写在明处。**
不承诺排名、不承诺被 AI 引用；演示数据明确标注"部分为演示数据"；招商页写明"不构成收益承诺"。行业乱象我们改变不了，但**我们自己不掺和**。

**⑩ 每日只做 3 件事。**
这是产品设计上最"反直觉"、也最被用户认可的一点：我们把复杂的推广收敛成**当天最该做的 3 件事**。不需要你懂 GEO、懂 SEO、懂算法，跟着做就行。**降低门槛，比堆功能更重要。**

## 二、安装与启动

### 方式一：安装版（推荐）

1. 双击 `GEO霸屏系统_1.0.0_x64-setup.exe` 进入安装向导；
2. 若 Windows 弹出蓝色提示（"Windows 已保护你的电脑"），点 **更多信息 → 仍要运行**（未购买数字签名证书时的正常提示，不是病毒）；
3. 按提示点「下一步」即可，程序安装在当前用户目录，**不需要管理员权限**；
4. 完成后，**桌面和开始菜单**出现「GEO霸屏系统」图标，双击即可使用。

### 方式二：免安装版

解压 `免安装版_GEO霸屏系统_1.0.zip`，双击里面的「GEO霸屏系统.exe」直接用，不用安装。

> **系统要求**：Windows 10 / 11（64 位）。安装包已内嵌 WebView2 运行时的自动安装引导，若系统缺失会自动补齐，无需手动处理。

每个分站的每个页面都铺设本地区域关键词，用于承接区域长尾流量。

### 5. 资源中心

14 大类资源，按"对 AI 可信度的影响"排序：企业信息核验平台、百科、问答社区、权威媒体、搜索引擎、AI 系统、内容平台、行业垂直、B2B、外链站、地图本地、软件站、分类信息、网友共建。

### 6. 积分与排行榜

完成资源提交、作业回填、效果确认等动作即可获得积分。积分可兑换 30 天复测、AI 可见度检测、内容稿、高级模板等权益。

## 四、常见问题（FAQ）

**Q1：首次打开弹出蓝色警告怎么办？**
点「更多信息 → 仍要运行」。这是未购买数字签名证书的正常提示，仅首次出现。

**Q2：打开后显示"暂时连不上服务器"？**
检查网络；页面每 5 秒自动重试，也可点「重新连接」。页面下方有客服联系方式，或直接到官网 https://yaduoo.cn 继续使用——登录同一账号，数据自动同步。

**Q3：点了关闭窗口，程序还在？**
正常。它是常驻程序，收在右下角托盘里。要完全退出，请右键托盘图标选「退出」。

**Q4：不想让它开机启动？**
右键托盘图标，取消勾选「开机自动启动」。

**Q5：收不到每日提醒？**
检查 Windows「设置 → 系统 → 通知」是否允许本程序通知；也可在托盘菜单点「现在提醒我一次」测试。

**Q6：需要自己设置服务器地址吗？**
不需要。客户端已内置正式官网地址，安装后打开即用。如果将来地址有变更，由我们在客户端内处理，你这边不用做任何操作。

**Q7：积分能提现吗？**
不能。积分用于兑换权益；能提现的是推广分成，两者是分开的两条轨。

**Q8：你们能保证排名吗？**
不能，也不会承诺。任何声称"保证排名""保证被 AI 推荐"的，都值得警惕。我们交付的是过程与动作，以及可复测、可对比的效果记录。

**Q9：想换电脑用？**
免安装版直接拷走；安装版在新电脑再装一次，数据都在云端。

**Q10：想卸载？**
Windows「设置 → 应用」里找到「GEO霸屏系统」卸载。卸载不会删除云端数据。
